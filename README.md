# SelfLearningAI

한국어로 사용하는 독립 프로그램입니다. 첫 개발 분야는 장기 기억과 증거에 따른 판단 갱신입니다. Python 3.10 이상과 표준 라이브러리만 사용합니다.

## 실행

SelfLearningAI의 개발 목표는 스스로 학습하고 이해하며 판단을 갱신하는 기본 지능입니다. 현재 구현 범위는 장기 기억, 증거에 따른 잠정 판단, 기억을 바탕으로 한 탐구입니다.

### TEST와 CLEAN

| 구분 | TEST | CLEAN |
| --- | --- | --- |
| 프로그램 폴더 | `TEST/` | `CLEAN/` |
| 실행 파일 | `TEST/run.py` | `CLEAN/run.py` |
| 코드 | 이 파일에서 개발 | 통과한 TEST 코드를 이 파일에 반영 |
| 배포 시 기억 | 개발 중 얻은 지식·기억·경험 포함 | 빈 상태에서 시작 |
| 평가 자료와 결과 | 포함 | 제외 |
| 제공 후 학습 | 가능 | 가능 |

각 폴더의 `run.py`는 그 폴더 안의 모듈을 사용합니다. `selflearningai/cli.py`는 명령 실행, `memory.py`는 학습·장기 기억·판단, `research.py`는 탐구와 인용 검사를 담당합니다. 기억 파일의 기본 위치도 각 프로그램 폴더입니다.

TEST는 `TEST/test.sqlite3`에 기억을 저장하며, 이 파일이 없으면 `TEST/memory.sqlite3`를 이어서 사용합니다. TEST의 `--기억파일 경로`로 별도 TEST 기억 파일을 열 수 있습니다. CLEAN은 `CLEAN/clean.sqlite3`로 시작하며, TEST 데이터베이스를 복사하거나 이름을 바꿔도 종류 표시를 검사해 거부합니다. 이전 버전에서 폴더 밖에 만든 기억 파일을 계속 쓰려면 같은 종류의 프로그램 폴더에 두면 됩니다.

저장소 루트에서 실행하는 예입니다. ZIP을 펼친 경우 각 프로그램 폴더 안에서 `python3 run.py`에 명령을 붙입니다.

```bash
python3 TEST/run.py 기록 "가상 관측소의 야간 운영"
python3 CLEAN/run.py 학습 "공원의 야간 개방" "개방" "현장 관찰" "출입문이 열려 있었다."
python3 CLEAN/run.py 판단 "공원의 야간 개방"
```

## 검사와 판단

입력의 공백과 유니코드를 정규화하고 필수 항목, 길이, 제어 문자, 같은 주제에서 출처의 최신 기록과 동일한 입력을 검사합니다. 통과한 증거는 SQLite 트랜잭션으로 저장합니다. SQLite 트리거가 행의 일반적인 수정과 삭제를 차단합니다. 파일과 스키마에 직접 접근할 수 있는 사람에 대한 변조 방지는 운영체제 권한에 의존합니다.

같은 출처의 보완과 정정은 새 기록으로 저장합니다. 판단에는 주제별로 각 출처의 최신 기록만 반영하고, 가장 많이 지지받은 주장을 잠정 판단으로 표시합니다. 동률이면 보류합니다. 기존 주장을 지지한 기록은 이후 판단이 바뀌어도 조회할 수 있습니다. 주제와 주장의 비교는 정규화된 문자열 기준입니다. 입력은 현재 사람이 제공하며 증거의 진위나 출처 간 독립성은 판단하지 않습니다.

## 다음 탐구 주제 선택

```bash
python3 TEST/run.py 탐구
```

기억에 있는 주제를 검토해 가장 많은 지지를 받은 주장이 동률인 주제, 의견이 갈리는 주제, 출처가 한 곳뿐인 주제 순서로 선택합니다. 의견이 갈리는 주제끼리는 상위 두 주장 간 출처 수 차이가 작은 주제를 먼저 확인합니다. 우선순위가 같으면 최근에 증거가 추가된 주제를 먼저 선택합니다. 선택 이유와 확인할 질문을 출력합니다. 탐구 주제는 기억에서 선택합니다. 선택한 주제를 로컬 자료에서 조사하려면 자료 파일을 지정합니다.

```bash
python3 TEST/run.py 탐구 --자료 운영.txt --자료 관측.txt
```

각 UTF-8 파일에서 주제 문구가 나오는 줄을 최대 3개씩 찾습니다. 비교할 때 유니코드와 공백을 정규화합니다. 파일당 최대 1 MiB를 읽으며 후보마다 파일 경로, 줄 번호, 구절, 원본 파일의 SHA-256을 표시합니다. 후보는 판단을 위한 검토 자료이며, 진위나 지지 여부를 자동 판정하거나 기억에 자동 등록하지 않습니다.

## 확인한 인용을 기억에 통합

```bash
python3 TEST/run.py 인용학습 "공원의 야간 개방" "폐쇄" "관리소" 운영.txt 2
```

프로그램은 지정한 줄에 주제 문구가 있는지 확인합니다. 검사를 통과하면 인용문과 파일 경로, 줄 번호, 현재 파일의 SHA-256을 증거에 함께 저장합니다. 사용자가 주장과 출처를 지정하며 같은 출처의 이름을 일관되게 써야 정정으로 집계됩니다.

탐구 때와 파일 내용이 바이트 단위로 같은지 확인해야 할 때는 줄 번호 뒤에 탐구 결과의 SHA-256을 붙입니다. 생략하면 등록 시점의 파일을 기준으로 검사합니다. 인용문이 주장을 뒷받침하는지와 출처의 신뢰성은 사용자가 판단합니다.

## 관측 자료에서 학습할 주제 선택

다음 형식의 UTF-8 JSON 파일을 관측 자료로 제공합니다. 파일당 최대 1 MiB입니다. `--자료`를 반복해 최대 8개 파일을 함께 읽을 수 있고, 관측은 모든 파일을 합쳐 최대 100건입니다.

```json
[
  {
    "주제": "공원의 야간 개방",
    "주장": "폐쇄",
    "출처": "관리소 공지",
    "증거": "야간 출입 금지 시간이 공지됐다."
  },
  {
    "주제": "도서관 운영",
    "주장": "개방",
    "출처": "방문 기록",
    "증거": "오전 10시에 입장했다."
  }
]
```

```bash
python3 TEST/run.py 자율학습 --자료 관측.json
python3 CLEAN/run.py 자율학습 --자료 관측.json
```

개발 중에는 TEST에서만 학습합니다. CLEAN 명령은 사용자가 배포본에서 자기 자료로 학습할 때 사용합니다.

프로그램이 자료에서 새로운 관측이 있는 주제 하나를 선택합니다. 기존 기억에서 판단이 갈리거나 출처가 부족한 주제를 탐구 순위에 따라 먼저 선택합니다. 그 밖에는 새로운 출처 기록이 많은 주제를 고르며, 수가 같으면 주제명 순서로 고릅니다. 입력 자료 전체에서 같은 주제·출처의 내용이 충돌하면 저장 전에 거부합니다. 이미 보존된 관측은 재등록하지 않습니다. 선택한 주제의 새 관측은 한 트랜잭션에 통합하고 잠급니다. 한 번에 한 주제를 학습합니다. `--계속`을 붙이면 남은 주제를 차례로 선택하고, 새 관측이 없을 때 종료합니다. 연속 학습에서도 주제마다 따로 저장하므로 이후 주제 저장에 실패하면 그 주제만 되돌립니다.

### 한국어 텍스트 자료

UTF-8 `.txt` 파일에는 아래와 같이 관측을 적습니다. 관측과 관측 사이는 빈 줄로 나눕니다.

```text
주제: 공원
출처: 오전 안내문
관측: 공원은 개방입니다.

주제: 도서관
출처: 운영 공지
관측: 도서관은 폐쇄이다.
```

```bash
python3 TEST/run.py 자율학습 --자료 관측.json --자료 관측.txt --계속
```

관측 문장은 적어 둔 주제와 같은 명사구, 조사 `은/는/이/가`, 주장, 서술어 `이다/입니다` 순서로 씁니다. 주제가 한글 음절로 끝나면 받침에 맞는 조사인지도 확인합니다. 각 관측의 주장과 원문을 추출하여 한국어 증거로 기록합니다. JSON과 텍스트 모두 해당 자료 전체를 검사한 뒤 첫 주제 학습을 시작합니다. 현재 검사의 범위는 지원 문형, 자료 형식, 출처별 기록의 충돌과 중복입니다. 자유 형식 문서에서 주장 추출이나 출처의 실제 신원 및 진위 판정은 아직 지원하지 않습니다.

## 통합 테스트

```bash
python3 -m unittest discover -s tests -v
```

실제 CLI를 여러 프로세스에서 실행해 기억 유지, 판단 보류와 변경, 기존 증거 보존, 입력 검사, 출처 정정, 이전 형식 기억 파일의 자동 변환, 클린과 테스트의 격리, 선택적 인용 해시 확인, 데이터베이스 잠금을 확인합니다.

## TEST에서 개발하고 CLEAN에 반영

1. 개발 코드는 `TEST/selflearningai/`에서 수정합니다. 개발 중 학습에는 TEST 프로그램을 사용합니다.
2. TEST 전용 통합 테스트를 먼저 실행합니다.
3. `promote_test_code.py`가 TEST 코드 스냅샷으로 학습·평가를 실행합니다. 통과하면 평가한 Python 모듈을 `CLEAN/selflearningai/`에 반영합니다. 평가가 실패하면 CLEAN은 기존 모듈로 유지됩니다. 평가 디렉터리는 새 경로를 지정합니다.
4. 두 프로그램의 통합 테스트를 실행하고 각 폴더에서 배포본을 만듭니다.

```bash
python3 -m unittest discover -s tests -p test_integration.py -k TestProgramIntegrationTest
python3 tools/promote_test_code.py --output-dir TEST/evaluation-run
python3 -m unittest discover -s tests -v
python3 tools/build_distributions.py --test-db TEST/evaluation-run/test.sqlite3 --evaluation-dir TEST/evaluation-run/evaluation --output-dir dist
```

TEST ZIP을 풀면 프로그램 코드, 테스트 기억 및 평가 자료가 있는 `TEST/`가 생성됩니다. CLEAN ZIP을 풀면 프로그램 코드와 README가 들어 있는 `CLEAN/`이 생성됩니다. 배포 도구는 각 폴더에 있는 코드를 그대로 포장합니다.
