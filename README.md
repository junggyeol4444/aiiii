# SelfLearningAI

한국어로 사용하는 독립 프로그램입니다. 첫 개발 분야는 장기 기억과 증거에 따른 판단 갱신입니다. Python 3.10 이상과 표준 라이브러리만 사용합니다.

## 실행

저장소 루트에서 실행합니다. 아래 내용은 동작을 확인하기 위한 가상 예시입니다.

```bash
python3 -m selflearningai --help
python3 -m selflearningai --기억파일 예제.sqlite3 학습 "공원의 야간 개방" "개방" "현장 관찰" "출입문이 열려 있었다."
python3 -m selflearningai --기억파일 예제.sqlite3 학습 "공원의 야간 개방" "폐쇄" "관리 공지" "야간 폐쇄 공지를 확인했다."
python3 -m selflearningai --기억파일 예제.sqlite3 판단 "공원의 야간 개방"
python3 -m selflearningai --기억파일 예제.sqlite3 기록 "공원의 야간 개방"
```

`--기억파일`을 생략하면 현재 디렉터리의 `memory.sqlite3`에 기록합니다. 같은 파일을 사용하면 프로그램을 다시 시작한 뒤에도 기록을 조회할 수 있습니다.

## 검사와 판단

입력의 공백과 유니코드를 정규화하고 필수 항목, 길이, 제어 문자, 주제별 출처 중복을 검사합니다. 통과한 증거는 SQLite 트랜잭션으로 저장합니다. SQLite 트리거가 행의 일반적인 수정과 삭제를 차단합니다. 파일과 스키마에 직접 접근할 수 있는 사람에 대한 변조 방지는 운영체제 권한에 의존합니다.

같은 주제에서 각 출처를 한 번 계산하고 가장 많이 지지받은 주장을 잠정 판단으로 표시합니다. 동률이면 보류합니다. 기존 주장을 지지한 기록은 이후 판단이 바뀌어도 조회할 수 있습니다. 주제와 주장의 비교는 정규화된 문자열 기준입니다. 입력은 현재 사람이 제공하며 증거의 진위나 출처 간 독립성은 판단하지 않습니다.

## 통합 테스트

```bash
python3 -m unittest discover -s tests -v
```

실제 CLI를 여러 프로세스에서 실행해 기억 유지, 판단 보류와 변경, 기존 증거 보존, 입력 검사, 데이터베이스 잠금을 확인합니다.
